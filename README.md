# Dr. Mina Soliman — Emotion Wheel & Mind Sanctuary (Apple Web App)

Dedicated website for **iPhone, iPad, and Mac Safari** patients of **Dr. Mina Soliman, MD**.

## Features Included
- **Centered Interactive 3-Ring Wheel of Emotions** (`540x540` SVG viewBox, zero clipping)
- **Log Emotion to Journal** workflow with SUDS intensity, somatic cues & triggers (patient entries only — zero demo data)
- **Direct WhatsApp Booking & Emergency Line**: `https://wa.me/201026281035`
- **Therapeutic Guided Meditation** & offline Web Audio soundscape mixer with Screen Wake Lock support
- **iCloud Drive / Files JSON Backup & Restore** in Care & Contact so patients can safely back up or move logs between Safari and Home Screen
- **Full-Screen Apple Home Screen & Offline Support** (`apple-touch-icon.png`, `manifest.json`, `sw.js`, dynamic Safari `theme-color`)

## Instant Hosting (Get Your Shareable HTTPS Link)
1. Drag and drop **`DrMinaSoliman-Apple-Website.zip`** (or the contents of this folder) onto **[https://app.netlify.com/drop](https://app.netlify.com/drop)** — or push/upload to GitHub Pages.
2. Copy your HTTPS link and share it with Apple patients via WhatsApp.
3. On iPhone / iPad, patients open the link in **Safari → Share → Add to Home Screen** (or on Mac Safari: **File → Add to Dock…**) to install full-screen with Dr. Mina Soliman's app icon.
